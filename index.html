🔔 Tutorial: notificações fora do site

Como vai funcionar

Para o TarefaMix avisar você mesmo quando estiver fechado, são necessários estes passos:

1. Site seguro

O TarefaMix precisa estar publicado em HTTPS. O endereço atual já usa HTTPS.

2. Autorizar avisos

Quando o recurso estiver pronto, clique em “Permitir” no navegador para receber notificações.

3. Receber o lembrete

Um serviço de notificações envia o aviso no horário escolhido, mesmo com o site fechado.

O que falta neste momentoO lembrete atual só funciona enquanto a página está aberta. Para funcionar fechada, ainda precisamos conectar um serviço push ao TarefaMix; permitir avisos no navegador sozinho não ativa essa função.
